# 🔮 오늘의 운세

오늘 날짜를 기반으로 운세를 보여주는 심플한 웹 프로토타입입니다.

## 실행 방법

별도 설치 없이 `index.html` 파일을 브라우저에서 바로 열면 됩니다.

## 기능

- 오늘 날짜 자동 표시
- **운세 보기** 버튼 클릭 시 운세 결과 표시
- 운세 등급 5단계: 대길(大吉) / 길(吉) / 소길(小吉) / 평(平) / 흉(凶)
- 카테고리별 별점: 재물운 / 건강운 / 애정운 / 직업운
- 오늘의 행운 숫자

## 특징

날짜를 시드(seed)로 사용하는 의사난수 방식이라, **같은 날에는 항상 같은 운세**가 나옵니다.
